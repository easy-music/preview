# Easy Music. 

- Наш проект это аналог Spotify. 
## Архитектура

```
Load Balancer ->
Api-gateway   ->
Services:
    - auth
    - user (аккаунт, плейлисты, авторы) 
    - recommends (рекомендации треков)
    - songs (обрабатывает новые песни, которые поступают в S3)
    - search(поиск по песням, исполнителям)
```

- Технологии:
1) сервисы api-gateway (https на внешку и внутри по grpc/http общается, также сервис использует Redis как кэш), auth (grpc, Postgres как БД), user(grpc, Postgres как БД) на Go
2) сервисы songs (http, связан с S3) и search (http, поиск в elasticsearch) написать на C++ 
3) сервис рекомендаций на Python (обшается через Kafka с сервисом user)
4) метрики: prometheus и визуализация grafana
5) трейсы: open telemetry и визуализация jaeger
6) логи: сборщик + elasticsearch + визуализация
7) деплой: сервис -> контейнер в регистри -> k8s
